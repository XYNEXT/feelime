# T9 九宫格（数字键面拼音）

九宫格模式（issue #1/#2）：键面是数字 1-9，候选出词，26 键用户零学习成本切换。

## 1. 原理（纯 schema，零引擎改动）

- `luna_pinyin_t9.schema.yaml` 由 `scripts/generate-t9-schema.py` 从全拼
  schema 生成：speller/algebra 里一条 `xlit` 把每个音节的拼写**原位**映射成
  数字串（abc→2 … pqrs→7 tuv→8 wxyz→9），alphabet 换成 `23456789`，
  无 abbrev（简拼会让单键歧义爆炸），校准 derive 全部去掉。
- librime 的 Script 是「拼写 → 音节集合」的多值映射（Dump 里续行首列为空），
  同一个数字串对应的全部同码音节都保留：`24 → ai/bi/ci`。
- 数字切分歧义（`9426` = xian 或 xi'an）由 librime 的音节图自然枚举，
  词频排序；`'` 分词键保留，用于手动消歧。
- prism 独立命名 `luna_pinyin_t9`（fuzzy 先例，double-pinyin.md §2.2 同一
  构建链），约 11KB；table/reverse 与全拼**逐字节相同**（音节 id 是词典级
  的，与 algebra 无关——这是 fuzzy/T9 变体能共享 table 的根据）。

## 2. 接线

- 原生：`InputMode.T9("t9")` → `EngineFactory` 建 `luna_pinyin_t9` 会话；
  `EngineDataStore.isModeReady` 按 schema 文件就绪判定。
- 键盘：`MODES.t9`（layout `t9`：三行数字键 + 分词/退格 + 固定底排），
  长按中/英键的模式菜单选择；`isChineseMode()` 包含 t9（分词键、全角标点）。
- 联想：T9 上屏后同样出接续词（association.md §3 的模式清单包含 t9）。
- 模糊音：不影响 T9（模糊 derive 在 pinyin 域，数字串不经模糊）。

## 3. 已知边界

- 候选条的 preedit 显示数字串（不显示拼音回显）；拼音回显（显示匹配到的
  音节串）留作后续增强，需要 translator/preedit 或自定义通道。
- `1`/`0` 键在组合中是死输入（无字母），空闲时按字面上屏。
