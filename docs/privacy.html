Feelime Privacy Policy

Effective: 2026-09-08 · Version 1.0

Feelime (the "app") is an offline-first keyboard app for Android. Its design principle: your input data never leaves your device.

What we collect

We do not collect, store, or transmit any personal data to any server. Specifically:

  • Text you type, candidate words, and voice audio are processed locally on your device and never pass through any server;
  • Speech recognition and sentence correction run on on-device models — no cloud service involved;
  • The app contains no ads, analytics, or crash-reporting SDKs.

When the app uses the network

The following features require a network connection and happen only when you explicitly trigger them:

  • Voice model download: on first use of offline voice input, model files are downloaded from GitHub Releases or HuggingFace mirrors;
  • Keyboard updates: checking for and downloading keyboard update packages (GitHub).

These requests contain none of your input. As with any network request, the servers you contact (GitHub, HuggingFace, and their mirrors) can see your IP address — an inherent property of internet communication.

Data storage and deletion

Your settings, saved phrases, clipboard history, and user lexicon live entirely in the app's private directory on your device, unreadable by other apps. Uninstalling the app permanently erases all of it.

Permissions

  • RECORD_AUDIO (microphone): recording happens only while the voice key is held; it stops on release and is never saved or uploaded;
  • INTERNET / ACCESS_NETWORK_STATE: used solely for the download and update checks described above, and for warning about metered networks before model downloads;
  • Input method service binding: required by Android to commit text into input fields;
  • Home-screen shortcuts and the quick-settings tile are created through the system ShortcutManager / tile APIs — launching them only switches your active keyboard and opens no web content.

Open source

The app is fully open source; every claim above is verifiable in code: github.com/feelime/feelime.

Changes to this policy

Substantive changes will update the version number and effective date on this page, announced in-app or in release notes.

Contact

Questions about this policy or data handling: open a GitHub Issue.

Feelime 隐私政策

生效日期：2026-09-08 · 版本 1.0

Feelime（下称"本应用"）是一款离线优先的 Android 输入法。本项目的设计原则是：你的输入数据不出设备。

我们收集什么

我们不收集、不存储、不向任何服务器传输你的个人数据。具体而言：

  • 你输入的文字、候选词、语音录音均在设备本地处理，全程不经过任何服务器；
  • 语音识别与整句纠错由设备上的本地模型完成，不使用云服务；
  • 本应用不含广告、统计分析或崩溃上报 SDK。

本应用何时访问网络

以下功能需要联网，且仅在你主动触发时发生：

  • 语音模型下载：首次使用离线语音时，从 GitHub Releases 或 HuggingFace 镜像下载模型文件；
  • 键盘更新：检查并下载键盘更新包（GitHub）。

这些请求不包含你的任何输入内容。与所有网络请求一样，所访问的服务器（GitHub、HuggingFace 及其镜像）能看到你的 IP 地址，这是互联网通信的技术必然。

数据存储与删除

你的设置、常用语、剪贴板历史、用户词库等全部保存在设备本地的应用私有目录中，其他应用无法读取。卸载本应用即彻底删除全部数据。

权限说明

  • RECORD_AUDIO（麦克风）：仅在按住语音键时录音，松开即停止，录音不保存、不上传；
  • INTERNET / ACCESS_NETWORK_STATE（网络）：仅用于上述模型下载与更新检查，以及在模型下载前对计费网络进行提醒；
  • 输入法服务权限：Android 系统要求，用于在输入框中上屏文字；
  • 桌面快捷方式与快捷设置磁贴通过系统 ShortcutManager / 磁贴 API 创建——点按它们只会切换当前输入法，不会打开任何网页内容。

开源

本应用完全开源，上述声明可由代码验证：github.com/feelime/feelime。

政策变更

若本政策发生实质性变更，我们会在本页面更新版本号与生效日期，并通过应用内公告或发布说明告知。

联系方式

对本政策或数据处理有任何疑问，请提交 GitHub Issue。
